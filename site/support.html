Help desk

How can we help?

Send a bug report, accessibility issue, privacy request, or release question. Please keep secrets out of the form.

Useful details

For a game issue, tell us the game type, board size, difficulty, what you expected, and what appeared. A game ID can help locate a privacy or reliability issue, but do not include chat transcripts unless they are essential and safe to share.

Never send: passwords, API keys, payment details, government IDs, private keys, or sensitive personal records.

Source bugs can also be reported in the public GitHub issue tracker if they contain no private information.

Submitting sends these fields to Formspree for delivery to the project owner. See Privacy.
